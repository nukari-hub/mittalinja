# SEO & AEO/GEO Optimointi - Mittalinja A1

## Toteutetut optimoinnit

### 1. **Structured Data (Schema.org JSON-LD)**

#### Organization Schema
- Yrityksen perustiedot
- Logo ja yhteystiedot
- Toiminta-alue
- Perustamisvuosi

#### Local Business Schema  
- ProfessionalService tyyppi
- Täydelliset yhteystiedot
- Geo-koordinaatit (60.2934, 25.0419)
- Aukioloajat
- Arvostelut (4.9/5, 45 arvostelua)

#### Service Schema
- 6 pääpalvelua strukturoitu
- Jokaiselle palvelulle oma Schema
- Linkitys organisaatioon
- Toimialue määritelty

#### FAQ Schema
- 5 yleisintä kysymystä strukturoitu
- Optimoitu AI-hakukoneille
- Selkeät kysymys-vastaus parit

#### Breadcrumb Schema
- Sivuston navigaatiorakenne
- Helpottaa crawlausta

### 2. **Meta Tags - Perus SEO**

#### Primary Tags
```html
<title>Mittalinja A1 Oy | A1-Luokan Mittauspalvelut Helsinki, Vantaa, Espoo</title>
<meta name="description" content="A1-luokan mittauspalveluja vuodesta 2004..." />
<meta name="keywords" content="mittauspalvelut, rakennusmittaus, maanmittaus..." />
```

#### Open Graph (Facebook, LinkedIn)
- og:title, og:description, og:image
- og:locale="fi_FI"
- og:type="website"

#### Twitter Cards
- twitter:card="summary_large_image"
- Kaikki tarvittavat meta tagit

### 3. **Geo-lokalisaatio**

```html
<meta name="geo.region" content="FI-18" />
<meta name="geo.placename" content="Vantaa" />
<meta name="geo.position" content="60.2934;25.0419" />
<meta name="ICBM" content="60.2934, 25.0419" />
```

### 4. **AI-spesifiset Meta Tagit (AEO/GEO)**

#### AI Summary
Tiivistetty yhteenveto AI-hakukoneille:
- Yrityksen pääpalvelut
- Tarkkuudet (±1-2mm, ±1-3cm, jne.)
- Laitteet (Leica, Trimble)
- Vastausaika (24h)
- Yhteystiedot

#### Answer Engine Ready
```html
<meta name="answer-engine-ready" content="true" />
<meta name="chatgpt-description" content="..." />
```

### 5. **Semantic HTML**

- Kieli asetettu: `<html lang="fi">`
- Theme color: `#2563EB` (sininen)
- Preload kriittiset resurssit (logo)
- Proper heading hierarchy (h1 → h6)

### 6. **Performance Optimoinnit**

- Font preconnect (Google Fonts)
- Resource preloading
- Inter font family (400-800 weights)
- Optimoitu kuvien lataus
